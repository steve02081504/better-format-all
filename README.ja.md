# format-all

[English](README.md) · [简体中文](README.zh-cn.md) · **日本語** · [Français](README.fr.md) · [Español](README.es.md) · [हिंदी](README.hi.md)

エクスプローラーの右クリック メニューから、フォルダー内の git 管理下または未コミットのすべてのファイルを、エディターの既定のフォーマッターでフォーマットします。

## 機能

- **フォルダー全体をフォーマット** — エクスプローラーで任意のフォルダーを右クリックし、**フォルダー内のすべてのファイルをフォーマット** を選択します。
- **変更されたファイルだけ** — 初回はすべての追跡ファイルをフォーマットし、以降は最後に完全にフォーマットしたコミット以降に変更されたファイルと、git が無視しない未追跡ファイルだけをフォーマットします。未コミットの変更は常に対象になります。
- **サブパスごとに最小限の処理** — 最後に完全にフォーマットしたコミットをサブパスごとに `.git/format-all.json` に記録するため、単独でフォーマットしたサブフォルダーを親フォルダーのフォーマット時にやり直しません。
- **既定のフォーマッター** — 「ドキュメントのフォーマット」を通すため、設定された `editor.defaultFormatter` が使われます。拡張機能が最初のフォーマッターを勝手に選ぶことはありません。
- **安全にキャンセル可能** — 進行状況の通知からキャンセルできます。キャンセルまたは一部失敗した実行はベースラインを**更新しない**ため、次回も未フォーマットのファイルがすべて対象になります。
- **UI のローカライズ** — VS Code の表示言語に従います。

## 使い方

1. エクスプローラーで git リポジトリ内のフォルダーを右クリックします。
2. **フォルダー内のすべてのファイルをフォーマット** を選択します。
3. 各ファイルが順に開かれ、既定のフォーマッターでフォーマットされ、保存されて閉じられます。

git リポジトリ内でないフォルダーを右クリックすると、エラーを報告して何も行いません。

## ベースラインの仕組み

- 状態は `.git/format-all.json`（`formatAll.stateFile` で変更可）に保存され、リポジトリからの相対パスを、そのパスを最後に完全にフォーマットしたコミット SHA に対応付けます。リポジトリのルートは空文字列 `''` です。
- ファイルは**記録された最も深い祖先または自身**をベースラインとして使います。あるパスを完全にフォーマットすると、その下のより細かいエントリは削除されます（親エントリが既にカバーしているため）。
- ベースラインがない場合は対象下のすべての追跡ファイルを、ある場合は `git diff <sha>` を**作業ツリー**と比較した変更ファイル（未コミットの編集も含む）と、無視されていない未追跡ファイルを選びます。
- ベースラインは対象が完全に終了したとき（キャンセルなし・失敗なし）にのみ書き込まれます。

## 設定

| 設定                         | 既定値            | 説明                                                               |
| ---------------------------- | ----------------- | ------------------------------------------------------------------ |
| `formatAll.stateFile`        | `format-all.json` | リポジトリの `.git` ディレクトリ内に書き込むファイル名。           |
| `formatAll.includeUntracked` | `true`            | git に追跡されておらず、無視もされていないファイルもフォーマット。 |

## 要件

- Visual Studio Code 1.100.0 以降。
- `PATH` に `git`。
- フォーマットする言語に既定のフォーマッター（`editor.defaultFormatter`）が設定されていること。フォーマッターのない言語のファイルは変更されません。
