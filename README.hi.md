# better-format-all

[English](README.md) · [简体中文](README.zh-cn.md) · [日本語](README.ja.md) · [Français](README.fr.md) · [Español](README.es.md) · **हिंदी**

एक्सप्लोरर के कॉन्टेक्स्ट मेन्यू से किसी फ़ोल्डर की सभी git-ट्रैक की गई या बिना कमिट वाली फ़ाइलों को उनके डिफ़ॉल्ट फ़ॉर्मैटर से फ़ॉर्मैट करें।

## विशेषताएँ

- **पूरा फ़ोल्डर फ़ॉर्मैट करें** — एक्सप्लोरर में किसी भी फ़ोल्डर पर राइट-क्लिक करें और **फ़ोल्डर की सभी फ़ाइलें फ़ॉर्मैट करें** चुनें।
- **केवल बदली हुई फ़ाइलें** — पहला रन सभी ट्रैक की गई फ़ाइलों को फ़ॉर्मैट करता है; बाद के रन केवल उन फ़ाइलों को फ़ॉर्मैट करते हैं जो अंतिम पूर्ण फ़ॉर्मैट किए गए commit के बाद बदली हैं, साथ ही वे सभी फ़ाइलें जो git द्वारा ट्रैक नहीं हैं और अनदेखी भी नहीं हैं। बिना कमिट वाले बदलाव हमेशा शामिल होते हैं।
- **प्रति सब-पाथ न्यूनतम कार्य** — अंतिम पूर्ण फ़ॉर्मैट किया गया commit हर सब-पाथ के लिए `.git/better-format-all.json` में याद रखा जाता है, इसलिए अलग से फ़ॉर्मैट किया गया सब-फ़ोल्डर बाद में उसके पैरेंट को फ़ॉर्मैट करते समय दोबारा नहीं किया जाता।
- **डिफ़ॉल्ट फ़ॉर्मैटर** — फ़ाइलें _Format Document_ से गुज़रती हैं, इसलिए कॉन्फ़िगर किया गया `editor.defaultFormatter` उपयोग होता है। एक्सटेंशन आपके लिए चुपचाप पहला फ़ॉर्मैटर नहीं चुनता।
- **रद्द करना सुरक्षित** — प्रगति सूचना से रद्द कर सकते हैं। रद्द किया गया या आंशिक रूप से विफल रन आधार को **अपडेट नहीं** करता, इसलिए अगला रन अभी भी सभी बिना फ़ॉर्मैट फ़ाइलों को देखता है।
- **स्थानीयकृत UI** — VS Code की प्रदर्शन भाषा का अनुसरण करता है।

## उपयोग

1. एक्सप्लोरर में किसी git रिपॉज़िटरी के अंदर किसी फ़ोल्डर पर राइट-क्लिक करें।
2. **फ़ोल्डर की सभी फ़ाइलें फ़ॉर्मैट करें** चुनें।
3. हर फ़ाइल क्रम से खुलती है, उसके डिफ़ॉल्ट फ़ॉर्मैटर से फ़ॉर्मैट होती है, सहेजी जाती है और बंद हो जाती है।

किसी git रिपॉज़िटरी के बाहर के फ़ोल्डर पर राइट-क्लिक करने पर त्रुटि मिलती है और कुछ नहीं होता।

## आधार कैसे काम करता है

- स्थिति `.git/better-format-all.json` में रहती है (`betterFormatAll.stateFile` से बदली जा सकती है)। यह रिपॉज़िटरी-सापेक्ष पाथ को उस commit SHA से जोड़ती है जिस पर वह पाथ आख़िरी बार पूरी तरह फ़ॉर्मैट हुआ था; रिपॉज़िटरी रूट खाली स्ट्रिंग `''` है।
- कोई फ़ाइल **सबसे गहरे दर्ज पूर्वज या स्वयं** को आधार बनाती है। जब कोई पाथ पूरी तरह फ़ॉर्मैट हो जाता है, तो उसके नीचे की अधिक विशिष्ट प्रविष्टियाँ हटा दी जाती हैं — पैरेंट प्रविष्टि उन्हें पहले ही कवर करती है।
- आधार न होने पर लक्ष्य की सभी ट्रैक की गई फ़ाइलें फ़ॉर्मैट होती हैं। आधार होने पर चयन `git diff <sha>` **कार्यक्षेत्र के विरुद्ध** (इसलिए बिना कमिट बदलाव भी गिने जाते हैं) और बिना ट्रैक व बिना अनदेखी फ़ाइलें होती हैं।
- आधार केवल तब लिखा जाता है जब लक्ष्य पूरी तरह पूरा हो जाए (कुछ रद्द नहीं, कोई विफलता नहीं)।

## सेटिंग्स

| सेटिंग                             | डिफ़ॉल्ट                 | विवरण                                                                              |
| ---------------------------------- | ------------------------ | ---------------------------------------------------------------------------------- |
| `betterFormatAll.stateFile`        | `better-format-all.json` | रिपॉज़िटरी की `.git` निर्देशिका में लिखा जाने वाला फ़ाइल नाम।                      |
| `betterFormatAll.includeUntracked` | `true`                   | उन फ़ाइलों को भी फ़ॉर्मैट करें जो git द्वारा ट्रैक नहीं हैं और अनदेखी भी नहीं हैं। |

## आवश्यकताएँ

- Visual Studio Code 1.100.0 या नया।
- `PATH` में `git`।
- जिन भाषाओं को फ़ॉर्मैट करना है उनके लिए डिफ़ॉल्ट फ़ॉर्मैटर (`editor.defaultFormatter`) कॉन्फ़िगर होना चाहिए; जिन भाषाओं का फ़ॉर्मैटर नहीं है उनकी फ़ाइलें अपरिवर्तित रहती हैं।
